# 参考专利库

本目录用于存放参考专利，供AI学习真实的专利撰写风格和技巧。

## 目录结构

```
reference_patents/
├── README.md           # 本说明文件
├── index.json          # 专利索引
├── power_system/       # 电力系统类专利
├── renewable/          # 新能源类专利
├── smart_grid/         # 智能电网类专利
├── protection/         # 继电保护类专利
└── automation/         # 电力自动化类专利
```

## 如何添加专利

### 方式一：直接粘贴文本

1. 在对应分类目录下创建 `.md` 文件，例如 `power_system/专利名称.md`
2. 按以下格式填写：

```markdown
# 专利名称

## 基本信息
- **专利号**：CN202XXXXXXXXX
- **申请日**：2024-01-01
- **申请人**：XXX公司
- **技术领域**：电力系统/配电网/...
- **IPC分类号**：H02J 3/00

## 权利要求书
[粘贴权利要求书全文]

## 说明书
[粘贴说明书全文]

## 学习要点
- 该专利的创新点在于...
- 权利要求的撰写特点是...
- 技术效果的描述方式是...
```

### 方式二：上传PDF/Word

将专利文件放入对应目录，文件名格式：`专利号_专利名称.pdf`

### 方式三：告诉我专利号

告诉我中国专利号（如CN202XXXXXXXXX），我来帮你整理。

## 专利分类标准

| 分类 | 目录 | 包含内容 |
|------|------|---------|
| 电力系统 | `power_system/` | 输电、变电、配电、用电等 |
| 新能源 | `renewable/` | 光伏、风电、储能、氢能等 |
| 智能电网 | `smart_grid/` | 配电自动化、需求响应、微电网等 |
| 继电保护 | `protection/` | 线路保护、设备保护、安全自动装置等 |
| 电力自动化 | `automation/` | 调度自动化、变电站自动化、监控系统等 |

## 学习要点提取

每份专利应提取以下学习要点：

1. **创新点**：该专利的核心创新是什么？
2. **权利要求结构**：独立权利要求和从属权利要求如何布局？
3. **技术效果描述**：如何描述技术效果？有无量化数据？
4. **术语使用**：使用了哪些专业术语？
5. **实施例撰写**：实施例如何详细描述？
6. **可学习的句式**：有哪些值得借鉴的句式？
