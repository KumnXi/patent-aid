# 专利法规知识库

本知识库整理了中国专利法、实施细则和审查指南中与专利撰写相关的关键条款。

## 目录结构

```
patent_law/
├── README.md                # 本说明文件
├── patent_law.json          # 专利法关键条款
├── implementing_rules.json  # 实施细则关键条款
├── examination_guidelines.json # 审查指南关键条款
└── common_rejections.json   # 常见驳回理由及应对
```

## 使用场景

1. **撰写时**：确保内容符合法规要求
2. **检查时**：引用具体条款指出问题
3. **答复审查意见时**：引用法规进行辩驳

## 重要提醒

- 本知识库基于2021年修订的《专利法》和2023年修订的《专利法实施细则》
- 法规条文可能更新，请定期核实
- 实际应用中应结合最新审查指南
