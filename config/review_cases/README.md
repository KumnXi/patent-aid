# 审查意见案例库

本目录存放真实审查意见和答复案例，用于指导专利撰写和答复。

## 目录结构

```
review_cases/
├── README.md               # 本说明文件
├── index.json              # 案例索引
├── novelty_issues/         # 新颖性问题案例
├── inventive_issues/       # 创造性问题案例
├── support_issues/         # 支持性问题案例
├── clarity_issues/         # 清楚性问题案例
└── sufficiency_issues/     # 充分公开问题案例
```

## 案例格式

每个案例文件按以下格式：

```markdown
# 案例名称

## 基本信息
- **专利号**：CN202XXXXXXXXX
- **技术领域**：电力系统/新能源/...
- **审查结论**：授权/驳回/视撤

## 审查意见摘要
[审查员提出的主要问题]

## 问题分析
- 问题类型：新颖性/创造性/支持性/...
- 问题本质：[分析审查员的核心关切]

## 答复策略
[如何答复该审查意见]

## 答复要点
1. [要点1]
2. [要点2]

## 最终结果
[最终审查结论]

## 经验总结
[从该案例中学到的经验教训]
```

## 学习目标

1. **了解审查员思维**：审查员关注什么？如何挑毛病？
2. **预防常见问题**：撰写时就避免这些问题
3. **积累答复经验**：遇到类似问题知道如何答复
