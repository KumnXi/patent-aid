# 技术效果描述库

本目录存放各类技术效果的规范描述方式，用于在不编造数据的前提下，有效表达技术方案的优势。

## 目录结构

```
effect_descriptions/
├── README.md              # 本说明文件
├── general_effects.json   # 通用技术效果描述
├── power_effects.json     # 电力系统效果描述
├── renewable_effects.json # 新能源效果描述
├── smart_grid_effects.json # 智能电网效果描述
└── quantification_guide.json # 量化描述指南
```

## 描述原则

1. **有数据时**：直接引用，注明来源
2. **无数据时**：使用定性描述，避免具体数值
3. **可推导时**：说明推导逻辑，使用"理论上"等限定词

## 效果描述分级

| 级别 | 描述方式 | 适用场景 |
|------|---------|---------|
| 有数据 | "根据实验数据，XX指标从A提升至B" | 交底书提供实验数据 |
| 可推导 | "根据XX原理，理论上可实现YY效果" | 可从技术方案推导 |
| 定性描述 | "有效提高/降低/改善..." | 无数据但逻辑上成立 |
| 相对描述 | "相比现有技术，具有优势" | 与现有技术对比 |
