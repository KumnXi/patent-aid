# 权利要求书模板

## 独立权利要求格式

```
1. 一种[主题名称]，其特征在于，包括：
[技术特征A]；
[技术特征B]；
[技术特征C]；
其中，[技术特征之间的关系说明]。
```

## 从属权利要求格式

```
2. 根据权利要求1所述的[主题名称]，其特征在于，[附加技术特征描述]。
```

## 常用句式

- "一种...装置/系统/方法，其特征在于，包括..."
- "所述[特征]包括..."
- "所述[特征]与所述[特征]通过...连接/耦合/通信"
- "其中，所述[特征]用于..."
- "所述[特征]为...中的至少一种"
- "根据权利要求N所述的...，其特征在于，..."
