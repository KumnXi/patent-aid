# 电力工程专利常用模板

## 虚拟电厂类

### 权利要求模板
```
1. 一种虚拟电厂调度方法，其特征在于，包括：
获取分布式能源资源的实时运行数据；
基于所述实时运行数据，建立虚拟电厂资源模型；
根据电网调度指令和所述虚拟电厂资源模型，生成调度策略；
将所述调度策略下发至各分布式能源资源执行。
```

### 技术效果量化
- 响应时间：从分钟级降至秒级（<5s）
- 调度精度：提升至95%以上
- 经济效益：降低运营成本15%-20%
- 新能源消纳率：提升至98%以上

## 分布式光伏类

### 权利要求模板
```
1. 一种分布式光伏发电系统功率预测方法，其特征在于，包括：
采集历史光伏发电数据和气象数据；
建立基于[算法]的功率预测模型；
利用实时气象预报数据进行功率预测；
根据预测结果进行电网调度优化。
```

### 技术效果量化
- 预测精度：MAPE<5%
- 预测时间尺度：15分钟-72小时
- 弃光率：降低至2%以下

## 电力巡检机器人类

### 权利要求模板
```
1. 一种电力设备巡检机器人，其特征在于，包括：
移动平台，用于在电力设施间移动；
多传感器模块，包括可见光相机、红外热像仪和超声波传感器；
数据处理单元，用于分析传感器采集的数据；
缺陷识别模块，基于深度学习算法识别设备缺陷；
通信模块，用于将巡检结果上传至监控中心。
```

### 技术效果量化
- 巡检效率：提升300%
- 缺陷识别准确率：>95%
- 巡检覆盖率：100%
- 人工成本：降低70%

## 配电网故障处理类

### 权利要求模板
```
1. 一种配电网故障定位与隔离方法，其特征在于，包括：
采集配电网各节点的电压和电流数据；
基于所述数据进行故障特征提取；
利用[定位算法]确定故障位置；
生成故障隔离方案并执行开关操作；
恢复非故障区域供电。
```

### 技术效果量化
- 故障定位精度：<100米
- 故障隔离时间：<30秒
- 供电恢复时间：<2分钟
- 停电范围：减少80%
