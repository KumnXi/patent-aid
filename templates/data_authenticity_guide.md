# 数据真实性快速参考卡

## 核心原则

**所有量化数据必须有来源，否则视为AI编造。**

## 四种数据来源

| 来源类型 | 是否可用 | 使用方式 |
|---------|---------|---------|
| 交底书明确提供 | ✅ 可用 | 直接使用，无需修改 |
| 行业公开标准 | ✅ 可用 | 标注标准号后使用 |
| 可从技术方案推导 | ⚠️ 需标注 | 标注推导依据后使用 |
| 无依据的具体数值 | ❌ 禁止 | 必须删除或改写 |

## 禁止出现的表述（无交底书支撑时）

❌ 绝对禁止：
- "降低XX%"、"提高XX倍"
- "响应时间<XXms"、"精度达到XX%"
- "节省XX元/度/吨"
- "经实验证明"、"测试结果表明"
- 任何看起来像实测数据的具体数值

## 安全替代表述

✅ 可以使用：
- "有效降低/提高..."
- "显著改善..."
- "相比现有技术，本方案具有更优的..."
- "理论上可实现..."
- "在优选实施方式中，可达到较优效果"
- "本领域技术人员可以理解，采用XX方案能够实现YY效果"

## 快速检查流程

```
检测到量化数据
    ↓
问：这个数据来自哪里？
    ↓
├─ 交底书 → ✅ 可用
├─ 行业标准 → ✅ 标注出处后可用
├─ 可推导 → ⚠️ 标注推导逻辑后可用
└─ 不知道 → ❌ 删除或改写为定性描述
```

## 实施例参数处理

| 情况 | 处理方式 |
|------|---------|
| 交底书有参数 | 直接使用 |
| 行业标准有参数 | 引用标准号 |
| 可计算的理论值 | 标注计算依据 |
| 交底书没有参数 | 用范围描述："温度为XX-YY℃" |
| 需要但无数据 | 标注："（注：具体参数需根据实验确定）" |

## 审查清单

在输出专利文件前，检查：
- [ ] 是否有无依据的具体百分比？
- [ ] 是否有无依据的具体数值？
- [ ] 是否有"经实验证明"等表述？
- [ ] 实施例参数是否有来源？
- [ ] 技术效果是否过度量化？

**只要有1处无依据的数据，整个文件就不能输出。**
